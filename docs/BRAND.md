# Имя продукта

Текущее имя — в `brand.env` (Peerage, `peerage`, `chat.peerage`). Сменить:

```bash
python3 scripts/rebrand.py <Name> <slug> <app.id>
```

Затем пересобрать `.so` для обеих ABI (`scripts/rebuild-android.sh <ABI>`) и APK, прогнать
тесты. Скрипт проверен туда-обратно: две смены подряд возвращают дерево байт в байт.

## Три вида имён в коде

| Вид | Примеры | При смене имени |
|---|---|---|
| **Имя** | название приложения (`app_name`), идентификатор и пакет Kotlin `chat.peerage`, JNI-символы `Java_chat_peerage_…`, крейты `peerage-*`, `libpeerage_android.so`, расширение бэкапа `.peerage`, документация | меняет `rebrand.py` |
| **Нейтральные** | `scripts/rebuild-android.sh`, тема `Theme.App`, каналы уведомлений, prefs `settings`, тег логов Rust `core`, путь сборки `/src` | не зависят от имени — не трогаются никогда |
| **Протокол** | метки `peerage:<домен>:vN` (вывод ключей, подписи, пролог Noise), магические байты `PEERBK` (бэкап), `PRGB` (блобы) | **заморожены**: скрипт их пропускает |

Почему протокол заморожен: от меток выводятся ключи, в том числе ключи шифрования
данных на диске, и подписи. Сменить метку — значит разорвать связь со всеми, у кого
старая версия, и сделать старые данные нечитаемыми. После переименования метки остаются
со старым именем навсегда (как «Whisper» в метках Signal после ухода от TextSecure).

## Правило для нового кода

- Видимое пользователю имя — только через `R.string.app_name`, не строкой.
- Новое техническое имя (канал, prefs, тег, временный каталог) — нейтральное, без бренда.
- Новая метка протокола — `peerage:<домен>:v1`, и это навсегда.

## Что вне репозитория

Каталог репозитория и репозиторий на GitHub называются по-старому — их переименование
отдельное решение (ссылки, локальные пути, память ассистента).

## Знак (иконка)

Кольцо — ты, сплошные точки — твои люди, линии — связи. Знак вырос из Tabler
«affiliate» (MIT): тот же расклад узлов, но малые узлы сплошные. От имени не зависит.

Геометрия задана в одном месте — `res/values/glyph.xml` (сетка 24×24). Её используют:
- `drawable/ic_glyph`: белый знак — индикатор сети в шапке, значок уведомления, монохромная иконка;
- `drawable/ic_launcher_fg`: знак цветом акцента, передний слой адаптивной иконки (знак 57.6 из 108dp);
- `mipmap-anydpi-v26/ic_launcher`: адаптивная иконка (фон, знак, монохромный слой для Android 13+);
- `mipmap/ic_launcher`: Android 7 — круг фона и тот же знак.

Цвета — `res/values/colors.xml`, зеркало `Tokens.Colors.bg` и `accent`.
