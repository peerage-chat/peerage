## P2 — Группы: UX-полиш + инвайты-как-сообщения — ✅ ЗАКРЫТ (2026-07-15)
- ✅ **Инвайты как «личные сообщения-приглашения»** (2026-07-15). `Payload::GroupInvite
  {gid,name}` (reliable) вместо тихого key-request → получатель видит карточку
  «Вступить/Отклонить» на экране Chats; accept шлёт KeyPackage → обычный join. Pending-
  инвайты персистятся (`pending_invites.json`) — переживают рестарт после Ack. Resync-
  путь (key-request) не тронут. Тест `invite_card_requires_accept_and_decline_clears`;
  живой прогон на меше. Решение владельца 2026-06-28.
- ✅ **Надёжный invite-хендшейк** (2026-07-02) — `group_key_request/reply` переведены на
  `send_reliable` (retry-until-Ack), Welcome уже был надёжен. Закрыта «последняя дыра
  доставки»: инвайт больше не теряется на холодной сессии. Покрыто loopback-тестами
  (`engine/tests/group_flow.rs`: invite/kick/leave, в т.ч. под потерями пакетов).
- ✅ **Имя группы передаётся** при вступлении (2026-07-15): админ после add рассылает
  служебный `AppMsg::Name` (JSON-конверт в MLS, как text/media), joiner ставит имя и
  персистит в `index.json`; имя из принятого инвайта применяется уже на Welcome.
  Тест `group_name_propagates_to_joiner`.
- ✅ Админка группы: список участников, удалить/добавить, выход (`AddMemberScreen`).
- ~~Подчистить осиротевший `Screen.Groups`~~ — **не dead-code**: экран подключён в
  навигации `MainActivity` (заметка устарела, проверено 2026-07-15).

## P3 = M2 — Унифицированные блобы + медиа в чате — ✅ ЗАКРЫТ (2026-07-14)
Крейт `blob` (BLAKE3, чанки, pull, анти-DoS) + конверт; картинки/файлы/голосовые/
аватарки — закрывает медиа-часть P1 И P2 разом. + metadata-scrub (EXIF). См. scope M2.

**Прогресс 2026-07-02 (data plane готов, весь под тестами без устройств):**
- ✅ Крейт `peerage-blob`: контент-адресный примитив (build/Reassembler/Manifest/Limits),
  по-чанковая + итоговая BLAKE3-проверка, анти-DoS. `cargo test -p peerage-blob` (хост).
- ✅ `blob::scrub`: снятие EXIF/GPS с JPEG/PNG без ре-энкода (PET-ось).
- ✅ Pull-протокол: `Payload/Event` Blob{Manifest,Request,Chunk} + `engine::blobs::
  BlobManager` (offer/докачка/отдача/tick). Loopback-тест `blob_flow` (вкл. потери).
  Ограничения из-за датаграммы 65535: CHUNK_SIZE 12 КБ, max_size 4 МБ, hex-поля.
- ✅ Проводка в движок: `BlobManager` в event_pump (Blob*-события → докачка/отдача,
  `tick`), приём → `data_dir/blobs/<id>` + событие `blob_received`; `Engine::blob_offer/
  blob_read/blob_id_hex`; JNI `blobOffer/blobIdHex/blobRead` + `Native.kt`.
- ✅ **Медиа-сообщения (2026-07-14):** `Payload::Media{id,hash,mime,name}` поверх
  надёжной доставки; `Engine::send_media` (scrub → push блоба → сообщение), приём с
  докачкой по хэшу. Тест `media.rs`.
- ✅ **Compose-UI:** пикер картинок (PickVisualMedia), файлы (OpenDocument), голосовые
  (MediaRecorder, hold-to-record) + воспроизведение; пузыри image/voice/file,
  фуллскрин-вьюер; аватарка по хэшу. Проверено вживую на устройстве.
- ✅ **Медиа в группах (2026-07-14):** JSON-конверт `AppMsg{Text|Media}` внутри MLS +
  push блоба каждому участнику (`Job::GroupMedia`). Тест
  `group_media_message_propagates`; живой смоук send-пути на эмуляторе.
