Рейл остаётся рейлом. Редактор открывается из меню и долгим тапом по плитке, а плитка + ведёт прямо в создание новой папки — то, чего сейчас в коде нет (Navigation.kt:66).

Живой счётчик обязателен. Правила «включить типы + добавить чаты − исключить» комбинируются неочевидно; без строки «попадает 4 чата» пользователь узнаёт результат только выйдя из редактора.

Удаление папки поясняется явно. Папка выглядит как контейнер, и без подписи «чаты останутся» удаление читается как удаление переписок.

Требует движка: состав, порядок и значок папок надо где-то хранить. Сейчас список зашит константой в Navigation.kt:36.
