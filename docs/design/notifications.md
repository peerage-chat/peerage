# Уведомления — проектирование (с 2026-10-31)

Проектируем так же, как экраны: варианты, а не первый попавшийся. **Документ —
источник истины по уведомлениям** (первый набросок из `app-ui.md` заменён им 2026-10-31).
Макеты — артефакт «Уведомления Peerage» (https://claude.ai/artifact/TYfNXnzhux2Jtrn8cnDURV);
сводка — раздел «Итог» в конце.

Ограничение платформы у нас одно, но главное: **пушей нет.** Уведомление строит сам
процесс, пока его держит `ConnService`; убитый процесс ничего не узнает, а при
следующем запуске собеседники досылают накопленное пачкой.

## Анатомия уведомления Android

Всё, что может быть в уведомлении одновременно. От этого набора отталкиваемся:
каждый вариант ниже — какие поля включить и как. Своё сверх шаблонов возможно только
собственным макетом, и тогда теряется системный вид.

### Видимые поля

| № | Поле | Что в нём бывает | Ограничения |
|---|---|---|---|
| 1 | Маленький значок | монохромный силуэт, он же в строке состояния | один цвет; тонируется акцентом |
| 2 | Имя приложения | «Peerage» | ставит система |
| 3 | Подтекст | короткая метка: чат, аккаунт, «3 новых» | одна строка в заголовке |
| 4 | Время | момент события; или секундомер / обратный отсчёт | — |
| 5 | Разворот | стрелка; в группе — число уведомлений | — |
| 6 | Аватар | большой значок или аватар разговора с бейджем приложения | у разговора — из ярлыка чата |
| 7 | Заголовок | имя чата или человека | — |
| 8 | Сообщения (MessagingStyle) | автор, его аватар, время и текст строки; в группе — имена | система показывает несколько последних |
| 9 | Картинка в сообщении | превью фото прямо в строке (Android 9+) | системе нужен файл картинки |
| 10 | Ответ из шторки | поле ввода; отправленное появляется строкой «Вы» | без открытия приложения |
| 11 | Подсказки ответов | чипы «Отлично!», эмодзи | система (Android 10+) или мы; можно запретить |
| 12 | Кнопки | «Ответить», «Прочитано», «Заглушить», «Перезвонить»… | не больше трёх |
| 13 | Пузырь | открыть чат плавающим окном | только разговоры; человек может запретить |
| 14 | Важный разговор | кольцо вокруг аватара, чат наверху «Разговоров» | включает человек долгим нажатием |
| 15 | Прогресс | полоса загрузки/передачи, точная или неопределённая | Android 16 — сегментированная |
| 16 | Шаблон звонка (CallStyle) | «Входящий / Идёт звонок» | только звонки, Android 12+ |
| 17 | Пометка проверки | строка под именем звонящего | в шаблоне звонка |
| 18 | Кнопки звонка | цветные «Отклонить» / «Ответить», у идущего — «Сбросить» | цвета — системные |
| 19 | Длительность | секундомер идущего звонка | — |
| 20 | Сводка группы | одна шапка над несколькими уведомлениями приложения | Android 7+ группирует и сам |
| 21 | Публичная версия | что видно на экране блокировки вместо настоящего | отдельный текст |
| 22 | Значок на иконке | точка или число на иконке приложения | число — не во всех лаунчерах |

### Невидимые свойства — поведение

| Свойство | Что даёт |
|---|---|
| Канал и важность | звук, вибрация, всплытие, значок в строке состояния; после создания канала меняет только человек |
| Всплывающее окно | при высокой важности выезжает поверх экрана на несколько секунд |
| Полный экран | входящий звонок на заблокированном телефоне — на весь экран (Android 14+: нужно разрешение) |
| Человек (`Person`) отправителя | исключения «Не беспокоить»: избранные контакты пробиваются сквозь тишину |
| Категория | «сообщение», «звонок», «прогресс» — по ней работает «Не беспокоить» |
| Звучать один раз | обновление уведомления не звенит заново — ключ к пачке после офлайна |
| Немое | без звука и вибрации |
| Постоянное | не смахивается (связь, идущий звонок) |
| Тайм-аут | исчезает само через заданное время |
| Закрыть по нажатию | после открытия уходит |
| Цвет / окраска | акцент тонирует значок и кнопки; заливка фона — только у звонков, медиа и постоянных служб |
| Видимость на блокировке | всё / публичная версия / скрыть |
| Нажатие и смахивание | что открыть по тапу, что сделать при смахивании (например, «прочитано») |
| Часы и машина | Wear OS и Android Auto показывают ответ и «прочитано», если кнопки помечены по смыслу |

**На реальных телефонах:** MIUI (Xiaomi) по умолчанию выключает всплывающие
уведомления новым приложениям, пока их не разрешить; оболочки производителей (MIUI,
One UI) перерисовывают шаблоны по-своему — ориентируемся на поведение, не на пиксели.

## Типы уведомлений (согласовано 2026-10-31)

1. Постоянное «связь» — держит `ConnService`.
2. Новое сообщение — личное и групповое.
3. Звонок — входящий, идущий, пропущенный.
4. Передача файла — скачивание (и отправка крупного).
5. Итог после офлайна — сколько сообщений, запросов.
6. Служебные — какие именно, решает пункт 10.
7. *(после 1.0, «Каналы»)* Новый пост.

## Настройки (согласовано 2026-10-31)

- **Как в Telegram:** звук, вибрация, важность и прочее настраиваются в самом приложении,
  а не только в системных настройках. Android не даёт менять категорию после
  создания, поэтому при смене настройки категория пересоздаётся под новым id
  (так делает Telegram).
- **Режим чата как в Discord:** «все сообщения» / «только упоминания» / «ничего».
  Отдельного «заглушить» нет: режим кроме «все» выбирается **с длительностью**
  (1 ч / 8 ч / сутки / пока не включу), по истечении сам возвращается к «все».
  «Заглушить на час» в шторке = «только упоминания» на час в группе, «ничего» на час в личном.
- **Режим по умолчанию задаёт владелец группы** (при создании и в настройках группы),
  поле едет вместе с именем группы. Новый участник получает его; свой выбор участника
  главнее; смена умолчания владельцем меняет режим только тем, кто свой не выбирал.
  Поле — в формат группы до беты (после — миграции).
- Экраны настроек (общие, профиль чата, группа) проектируются отдельно, вместе с остальным UI.
- Не в 1.0: свой звук для отдельного чата (исключения Telegram) — потом; светодиод — нет;
  «оповещать о реакциях» — вместе с реакциями.

## Передача файлов (согласовано 2026-10-31)

- Тихое уведомление с прогрессом; при нескольких передачах — **одно общее** (общий процент + список ↓/↑).
- Только «Отмена», без «Паузы»: докачка после обрыва и так автоматическая.
- Отправитель не в сети — серая полоса, «докачаем, когда появится».
- **Смахивается** (не `ongoing`): смахнул — не показываем до следующего события этой передачи
  (готово / ошибка); прогресс заново не всплывает. Отдельной кнопки «Скрыть» и авто-скрытия нет.
- «Скачано» — только для скачивания, запущенного вручную, и только если приложение свёрнуто;
  авто-вложения уведомлений не дают. Ошибка — всегда, с «Повторить».

## Карта решений

Где Android даёт разные пути и у нас есть выбор. Проходим по порядку; решение по
пункту записывается сюда же.

| № | Решение | Варианты (рабочие) | Итог |
|---|---|---|---|
| 1 | Сообщения | А — разговор на каждый чат; Б — одна сводка на приложение; В — без содержимого | **А** (2026-10-31): MessagingStyle на чат, «Ответить / Прочитано / Заглушить на час» |
| 2 | Постоянное «Связь» | а — свёрнутое и немое; б — статус сети и «Пауза на 1 ч»; в — сливается с непрочитанным | **в** (2026-10-31): тихое, минимальная важность (не поднимать); «В сети» / «Нет связи» / счётчик **всего непрочитанного**: «N новых от I контактов · вас упомянули · K запросов · пропущенный»; тап — список чатов, «Прочитать всё» |
| 3 | Пачка после офлайна | сколько звуков на 20 сообщений из 5 чатов: пять, один, ни одного | отдельной сводки нет — итог живёт в счётчике «связи» (п. 2); упоминания, запросы, пропущенные — пока тоже туда, потом смотрим вживую. **Досланное отличаем по возрасту:** сообщение, отправленное больше ~2 мин назад, — только в счётчик, без 1А и звука; свежее — 1А. Расхождение часов в пару минут допустимо (худшее — одно старое всплывёт отдельно) |
| 4 | Приложение открыто | баннер внутри приложения; только звук и счётчик; ничего | (2026-10-31) в том же чате — ничего; в другом месте — без шторки, счётчик в списке + короткий звук (настройка); баннер в приложении — отложен до экранов; звонки и ошибки передачи — всегда |
| 5 | Действия в шторке | «Ответить», «Прочитано», «Заглушить на час», реакция | «Ответить», «Прочитано», «Заглушить на час»; реакций в шторке **не будет** |
| 6 | Пузыри | поддерживать или нет | **нет в 1.0** (ярлыки чатов — да, без них нет «Разговоров») |
| 7 | Звонки | полноэкранный входящий, идущий с кнопками, голосовая комната в группе | (2026-10-31) **входящий** — системный шаблон звонка «Отклонить / Ответить», у видео + «Без видео»; на блокировке — наш полноэкранный экран (`call-ui.md`), нет разрешения Android 14 — подсказка при первом звонке. **Идущий** — секундомер, «Выкл. микрофон» + «Завершить» (комната — «Выйти», кто внутри). **Пропущенный** — строка в 1А чата с «Перезвонить»; досланный — в счётчик «связи». **Комната группы** — строка в 1А группы с «Присоединиться», только когда пустая комната ожила и режим группы «все». **Режим чата звонки не глушит** (не дозвониться — блокировка или выкл. звонки в общих) |
| 8 | Приватность | что на экране блокировки; сочетание с блокировкой приложения | (2026-10-31) данные под паролем и он не введён — только «Новое сообщение» (иначе невозможно); блокировка приложения включена — по умолчанию скрывать текст («Алиса: новое сообщение»), отдельная настройка может это отключить; экран блокировки телефона — по умолчанию только имя, настраивается |
| 9 | Звуки | системные; свой набор; разные для личных / групп / упоминаний | настраиваются в приложении, как в Telegram (см. «Настройки») |
| 10 | Служебное | запросы в контакты, приглашения, флуд, «вы офлайн» — что заслуживает шторки | (2026-10-31) свежие запросы («Принять / Отклонить», первое сообщение — по правилам приватности) и приглашения («Вступить / Отклонить»); **флуд — отдельным уведомлением** со звуком раз за эпизод («Сменить адрес / Уйти в офлайн»); «сам ушёл в офлайн» — **состояние «связи»**, не отдельное уведомление; остальное — только в приложении; смена ключа — пометкой в чате |

## Тексты

Системные тексты — **строгие и нейтральные**: состояние, а не разговор с человеком.
Без «вы / мы / вас» и разговорных глаголов. Не «Сообщения не приходят, пока вы не
вернётесь», «Ищем сеть…», «Докачаем, когда она появится», а «Офлайн-режим», «Поиск сети»,
«Отправитель не в сети». Подсказка — только если без неё непонятно, и тем же тоном.
Нынешние строки `notif_flood_*` / `notif_offline_*` переписать под это при реализации.

## Итог (2026-10-31)

**Постоянное «связь»** — одно на всё, тихое, минимальная важность. Состояния: «В сети»;
«N новых от I контактов · упоминание · K запросов · пропущенный» (тап — список чатов,
«Прочитать всё»); «Нет связи / Поиск сети»; «Офлайн-режим» с «Подключиться».

**Сообщение** — разговор на чат (MessagingStyle + ярлык чата), «Ответить / Прочитано /
Заглушить на час». Досланное (отправлено > ~2 мин назад) — только в счётчик «связи»,
без звука. Приложение открыто — в шторку ничего.

**Звонки** — системный шаблон: входящий (+ «Без видео»), идущий (секундомер, микрофон,
«Завершить» / «Выйти»); пропущенный и «комната ожила» — строки в разговоре чата.

**Передача файлов** — одно тихое уведомление с прогрессом, «Отмена»; смахнутое молчит до
готово/ошибки; «Скачано» — только ручное в фоне; ошибка — всегда.

**Служебные** — запрос в контакты, приглашение в группу, флуд.

**Настройки** — как в Telegram (в приложении, категория пересоздаётся); режим чата
«все / упоминания / ничего» с длительностью; умолчание группы — от владельца.

**Приватность** — под паролем без содержимого; при блокировке приложения текст скрыт
(настраивается) и **нет «Ответить / Прочитано»** — иначе шторка обходит блокировку;
экран блокировки — по умолчанию только имя.

**Категории Android** (согласовано 2026-10-31): Связь (мин.), Личные (выс.),
Группы (выс.), Упоминания (выс.), Входящие звонки (выс., рингтон), Идущий звонок (низк.),
Передача файлов (низк.), Запросы и приглашения (обычн.), Флуд (обычн.); после 1.0 — Посты
(низк.).

**Не в 1.0:** пузыри, свой звук на чат, светодиод, реакции, баннер внутри приложения,
«Новый пост» (каналы).
