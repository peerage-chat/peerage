# Уведомления — проектирование (с 2026-10-31)

Проектируем так же, как экраны: варианты, а не первый попавшийся. Текст в
`app-ui.md` → «Уведомления (согласовано 2026-10-30)» — первый набросок, **пересматривается
этим документом**; после прохода по пунктам ниже он заменится итогом.

Ограничение платформы у нас одно, но главное: **пушей нет.** Уведомление строит сам
процесс, пока его держит `ConnService`; убитый процесс ничего не узнает, а при
следующем запуске собеседники досылают накопленное пачкой.

## Анатомия уведомления Android

Всё, что может быть в уведомлении одновременно. От этого набора отталкиваемся:
каждый вариант ниже — какие поля включить и как. Своё сверх шаблонов возможно только
собственным макетом, и тогда теряется системный вид.

### Видимые поля

| № | Поле | Что в нём бывает | Ограничения |
|---|---|---|---|
| 1 | Маленький значок | монохромный силуэт, он же в строке состояния | один цвет; тонируется акцентом |
| 2 | Имя приложения | «Peerage» | ставит система |
| 3 | Подтекст | короткая метка: чат, аккаунт, «3 новых» | одна строка в заголовке |
| 4 | Время | момент события; или секундомер / обратный отсчёт | — |
| 5 | Разворот | стрелка; в группе — число уведомлений | — |
| 6 | Аватар | большой значок или аватар разговора с бейджем приложения | у разговора — из ярлыка чата |
| 7 | Заголовок | имя чата или человека | — |
| 8 | Сообщения (MessagingStyle) | автор, его аватар, время и текст строки; в группе — имена | система показывает несколько последних |
| 9 | Картинка в сообщении | превью фото прямо в строке (Android 9+) | системе нужен файл картинки |
| 10 | Ответ из шторки | поле ввода; отправленное появляется строкой «Вы» | без открытия приложения |
| 11 | Подсказки ответов | чипы «Отлично!», эмодзи | система (Android 10+) или мы; можно запретить |
| 12 | Кнопки | «Ответить», «Прочитано», «Заглушить», «Перезвонить»… | не больше трёх |
| 13 | Пузырь | открыть чат плавающим окном | только разговоры; человек может запретить |
| 14 | Важный разговор | кольцо вокруг аватара, чат наверху «Разговоров» | включает человек долгим нажатием |
| 15 | Прогресс | полоса загрузки/передачи, точная или неопределённая | Android 16 — сегментированная |
| 16 | Шаблон звонка (CallStyle) | «Входящий / Идёт звонок» | только звонки, Android 12+ |
| 17 | Пометка проверки | строка под именем звонящего | в шаблоне звонка |
| 18 | Кнопки звонка | цветные «Отклонить» / «Ответить», у идущего — «Сбросить» | цвета — системные |
| 19 | Длительность | секундомер идущего звонка | — |
| 20 | Сводка группы | одна шапка над несколькими уведомлениями приложения | Android 7+ группирует и сам |
| 21 | Публичная версия | что видно на экране блокировки вместо настоящего | отдельный текст |
| 22 | Значок на иконке | точка или число на иконке приложения | число — не во всех лаунчерах |

### Невидимые свойства — поведение

| Свойство | Что даёт |
|---|---|
| Канал и важность | звук, вибрация, всплытие, значок в строке состояния; после создания канала меняет только человек |
| Всплывающее окно | при высокой важности выезжает поверх экрана на несколько секунд |
| Полный экран | входящий звонок на заблокированном телефоне — на весь экран (Android 14+: нужно разрешение) |
| Человек (`Person`) отправителя | исключения «Не беспокоить»: избранные контакты пробиваются сквозь тишину |
| Категория | «сообщение», «звонок», «прогресс» — по ней работает «Не беспокоить» |
| Звучать один раз | обновление уведомления не звенит заново — ключ к пачке после офлайна |
| Немое | без звука и вибрации |
| Постоянное | не смахивается (связь, идущий звонок) |
| Тайм-аут | исчезает само через заданное время |
| Закрыть по нажатию | после открытия уходит |
| Цвет / окраска | акцент тонирует значок и кнопки; заливка фона — только у звонков, медиа и постоянных служб |
| Видимость на блокировке | всё / публичная версия / скрыть |
| Нажатие и смахивание | что открыть по тапу, что сделать при смахивании (например, «прочитано») |
| Часы и машина | Wear OS и Android Auto показывают ответ и «прочитано», если кнопки помечены по смыслу |

**На реальных телефонах:** MIUI (Xiaomi) по умолчанию выключает всплывающие
уведомления новым приложениям, пока их не разрешить; оболочки производителей (MIUI,
One UI) перерисовывают шаблоны по-своему — ориентируемся на поведение, не на пиксели.

## Карта решений

Где Android даёт разные пути и у нас есть выбор. Проходим по порядку; решение по
пункту записывается сюда же.

| № | Решение | Варианты (рабочие) | Итог |
|---|---|---|---|
| 1 | Сообщения | А — разговор на каждый чат; Б — одна сводка на приложение; В — без содержимого | |
| 2 | Постоянное «Связь» | а — свёрнутое и немое; б — статус сети и «Пауза на 1 ч»; в — сливается с непрочитанным | |
| 3 | Пачка после офлайна | сколько звуков на 20 сообщений из 5 чатов: пять, один, ни одного | |
| 4 | Приложение открыто | баннер внутри приложения; только звук и счётчик; ничего | |
| 5 | Действия в шторке | «Ответить», «Прочитано», «Заглушить на час», реакция | |
| 6 | Пузыри | поддерживать или нет | |
| 7 | Звонки | полноэкранный входящий, идущий с кнопками, голосовая комната в группе | |
| 8 | Приватность | что на экране блокировки; сочетание с блокировкой приложения | |
| 9 | Звуки | системные; свой набор; разные для личных / групп / упоминаний | |
| 10 | Служебное | запросы в контакты, приглашения, флуд, «вы офлайн» — что заслуживает шторки | |

Мнение модели по 1 и 2 (для спора, не решение): сообщения — «А» с настройкой «В» в
приватности; связь — «а».
