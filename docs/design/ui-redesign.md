# Перепроектирование UI (с 2026-11-01)

Рабочий документ прохода по всему мобильному UI. Идём так же, как с уведомлениями
([notifications.md](notifications.md)): сначала снимок «как сейчас», потом карта
решений по языку с вариантами, потом экран за экраном. Итог заменит соответствующие
разделы [app-ui.md](app-ui.md).

Все холсты с макетами (копии артефактов, ссылки на них) — в
[mockups/redesign/](mockups/redesign/README.md). Новый холст сразу кладётся туда же.

## Рамки (решения владельца 2026-11-01)

- **Глубина — «как пойдёт»:** язык июня 2026 (меню-свайп + рейл папок, квадратные
  аватары, «Telegram + Discord») не отбрасывается заранее, но и не защищается — каждое
  его решение проходит через карту решений.
- **Экран звонка — вне прохода:** он вылизан больше остальных ([call-ui.md](call-ui.md)).
- **Ландшафт и планшет — в 1.0.** Повёрнутый телефон — это маленький планшет, приложение
  должно в нём нормально работать. Поэтому каждый экран проектируется сразу в трёх
  ширинах (Compact / Medium / Expanded, ADR-005) и реализуется до релиза.
- **Опора** — [исследование «почему сыро»](../research/messenger-features.md), часть 2:
  многие причины там — решения UI (главный экран как адресная книга, нет «живых»
  сигналов, скачки экранов, технические слова, пустые состояния).
- **Одна тёмная тема.** Светлой нет; вся персонализация (тема, выбор акцента) — не раньше,
  чем после беты.
- **Крупный шрифт системы — обязателен.** Ни одной фиксированной высоты у строк, пузырей,
  кнопок с текстом: только минимальная (`heightIn(min = …)`), текст переносится. Размеры
  в макетах — минимумы при масштабе 1.0. Каждый экран проверяется на масштабе шрифта 1.3 и 2.0.

## Порядок

1. Снимок «как сейчас» — все экраны с эмулятора, телефон и ландшафт.
2. Карта решений по языку (ниже) — варианты с макетами, решает владелец.
3. Экран за экраном: телефон и планшет на одном холсте.
4. Итог → `app-ui.md`, затем реализация.

## Слои (с решения по главной, 2026-11-01)

Блоки читаются, только когда соседние слои заметно различаются по яркости. Нынешние
`#0F0F11` → `#1A1A1D` различаются на пару процентов — экран выглядит одним фоном.
Новая ступень (уточняется по ходу, в `Tokens.kt` — после итога):

| Слой | Цвет | Где |
|---|---|---|
| Фон | `#08090B` | под панелями, шапка главной |
| Панель | `#16171B` | лист со списком, панель чата |
| Ступень на панели | `#1C1D22` | закреплённая строка, поле, кнопка |
| Разделитель | `#222328` | внутри панели, от аватара |

## Экраны по одному (2026-11-01)

Все — в языке «лист»: шапка (назад, заголовок 22) на фоне, содержимое на панели группами.
Макеты — артефакт «Экраны Peerage».

- **Загрузка — А**: знак акцентом (`ic_launcher_fg`) по центру на `#08090B`, без подписи
  (имя менялось бы мимо `app_name`, см. `docs/BRAND.md`). Белый фон сейчас — не задан
  `windowSplashScreenBackground` в теме (Android 12+ подставляет свой).
- **Контакты**: в шапке поиск и «+» (добавить); сверху полоса «Запросы в контакты · N»
  (запросы переезжают сюда с главной); список по алфавиту с буквами-разделителями, статус
  сети, у сверенных — зелёный щит.
- **Звонки**: вкладки Все / Пропущенные; пока идёт звонок в комнате — зелёная полоса
  «Идёт звонок в «…» · N участников · Войти»; строки по дням: направление стрелкой,
  длительность, справа «перезвонить»; пропущенные — красноватым. **Подряд идущие звонки
  одной комнаты сворачиваются в строку «Группа (N)»**; при удалении группы её звонки
  удаляются из журнала (лечит «Удалённая группа · Звонок в комнате» пачками).
- **Сеть**: под заголовком статус («Подключено к мешу»), три плитки Пиры / Пинг / Трафик;
  на панели «Мой узел» (адрес + копировать, «Сменить адрес»), «Режим участия» (Узел сети),
  «Пиры · N» (первые два + «Все пиры»), отдельно офлайн-очередь и замер скорости.
  «Сеть и батарея» из старых настроек — сюда.
- **Хранилище**: сверху объём и полоса по типам (фото/видео/голосовые/файлы) с легендой;
  на панели резервная копия данных (дата последней), «По чатам» с размерами, «Очистить
  вложения».

## Чат группы и вложения (2026-11-01)

Макеты — артефакт «Экраны Peerage», третий ряд.

- **Шапка чата группы**: аватар-квадрат, имя, «N участников · M в сети», звонок в комнату, ⋮.
  Тап по шапке — профиль группы (не «Добавить участника»).
- **Баннер комнаты** (на панели, над закреплённым), пока идёт звонок: до 3 аватаров
  внахлёст + «+N», «Идёт звонок · N», подпись «Имя, Имя и ещё K · длительность», «Войти».
  Тот же вид — у полосы в «Звонках».
- **Входящие в группе**: мини-аватар слева, имя отправителя его цветом над текстом.
- **Выделение и упоминание не путаются**: выделение — заливка **всего ряда** (как сейчас,
  `selectedRow`) + круглая галка слева; упоминание меня — **обводка пузыря** акцентом,
  без заливки; «@ник» в тексте — акцентом.
- **Медиа и файлы** (из профиля чата/группы): шапка «Медиа и файлы · чат · N», вкладки
  Медиа / Файлы / Голосовые / Ссылки, разбивка по месяцам.
  - Медиа — сетка, **щипок меняет плотность 2 / 3 / 5 в ряд** (запоминается); у видео —
    длительность; нескачанное — **миниатюра** (уже есть отдельным блобом `thumbId` у фото
    > 512 КБ и видео) + круглая кнопка загрузки и размер.
  - Файлы — плитка с расширением, имя, «размер · отправитель · дата», у нескачанных —
    кнопка загрузки.
  - Голосовые — кнопка, волна, «длительность · отправитель · дата»; играющее — прогресс
    акцентом по волне.
  - Ссылки — плитка с буквой домена, домен, URL, строка сообщения с отправителем, дата.
    Превью страниц не грузим: запрос с устройства раскрыл бы сайту IP и факт открытия чата.

## Категории настроек (2026-11-01)

Макеты — артефакт «Настройки Peerage». Все тексты нейтральные.

- **Безопасность**: «Ключ» — резервная копия (статус, дата проверки), «Проверить ключ»,
  «Показать ключ» (после разблокировки); «Контакты» — «Сверенные контакты · N из M»;
  «Это устройство» — блокировка приложения, шифрование данных (уровень).
- **Приватность**: «По выбору» — отчёты о прочтении, индикатор набора (взаимно; шаг 7c
  беты); «Не отправляется» — номер, почта, список контактов; «Видят контакты» — статус
  «в сети» (из keepalive доставки), имя и аватар; «Заблокированные».
- **Уведомления** (по `notifications.md`): «Сообщения» — личные, группы, упоминания (внутри —
  полная настройка категории), «Текст в уведомлении»; «Звонки» — входящие; «Прочее» —
  запросы и приглашения, передача файлов, флуд, рост очереди; «Постоянное уведомление» —
  ссылка в системные настройки.
- **Медиа и звонки**: камера по умолчанию; **качество видео** — строка «Авто · до …» → список
  режимов, которые дают камера и видеоэнкодер этого устройства (`CameraCaps`), плюс «Авто»
  (по полосе); фиксированного 720p/1080p/4K нет (умолчание для звонка; во время звонка —
  долгое нажатие, как сейчас); звук — микрофон, вывод, качество Авто / Голос / Аудио; обработка
  (шумо-, эхоподавление, авто-громкость). **Потолок битрейта звука поднять:** сейчас
  `AUDIO_BITRATE_MAX` = 48 кбит → Авто 16–128, Голос до 32, Аудио 128 (музыка).
- **О приложении**: знак, имя, версия; транспорт, шифрование, лицензия; «Сохранить лог».
  Заглушка «настройки появятся ближе к релизу» — убрать.

## Напоминания о резервных копиях (2026-11-01)

Полоса над списком главной, того же вида, что полоса очереди. Навсегда не скрывается:
«Позже» только откладывает.

| Состояние | Полоса | Кнопки | Повтор |
|---|---|---|---|
| Копии ключа нет | оранжевая «Резервная копия ключа не сделана» | Сделать · Позже | через 1 день |
| Копия есть, подошёл срок | нейтральная «Проверка ключа · последняя — N дней назад» | Проверить · Позже | 7 → 14 → 30, дальше каждые 30 дней; «Позже» — на текущий интервал |
| Проверка не пройдена | оранжевая «Проверка ключа не пройдена» | Сверить · Проверить ещё раз | каждый день, пока не пройдена; после успеха — снова 7 → 14 → 30 |
| Копии данных нет / старше 30 дней | нейтральная «Копия данных — N дней назад» | Сделать копию · Позже | первая — не раньше 7 дней использования и при наличии переписки; «Позже» — 7 дней |

- **Проверка ключа** — ввести три слова по случайным номерам. Ввод — только слова словаря
  BIP39 (подсказка по буквам; слово однозначно по первым четырём), опечатка невозможна.
- **Ответ — один на все три слова**: «Слова не совпали», без указания, какое именно
  (иначе слова подбираются по одному). Общая подсказка — проверить нумерацию строк. Номера
  те же, три попытки; дальше — состояние «не пройдена».
- **«Сверить»** — показать весь ключ с номерами, только после разблокировки устройства
  (биометрия/PIN): человек сам находит и исправляет ошибку в записи. Новую копию не требуем.
- **Новый ключ не создаётся никогда** — это новая личность; «сделать копию» = переписать тот же.
- **Одна полоса-напоминание за раз**: ключ важнее данных; вторая — не раньше чем через 3 дня
  после того, как первую закрыли или выполнили. Полоса очереди — рабочая, вне этой очереди, выше.
- Полный ключ показывается и из «Профиль → Безопасность».

## Поиск в чате (2026-11-01)

Был не спроектирован: есть только глобальный поиск, экрана поиска внутри чата нет. Макеты —
артефакт «Поиск в чате Peerage».

- **Вход**: «⋮» в шапке чата → «Поиск»; плитка «Поиск» в профиле контакта/группы. Поле
  встаёт на место шапки чата; справа — «Перейти к дате».
- **Пустой запрос**: «Уточнить» — «От участника» (только группы) и «Перейти к дате»; ниже
  ярлыки разделов «Медиа и файлы» со счётчиками (оставлены, хоть и дублируют профиль). Подпись:
  поиск идёт по тексту на этом устройстве, запрос никуда не отправляется.
- **Два режима, одни фильтры — по умолчанию А**:
  - **А · В ленте** — чат на месте, совпадения подсвечены в пузырях, текущее ярче (заливка
    акцентом); вместо поля ввода — «N из M», «Списком», ↑ (старее) ↓ (новее).
  - **Б · Списком** — находки по дням: аватар, имя, время, две строки с подсветкой; сверху
    фильтры «От участника» и «Дата». Тап → находка в ленте (режим А) на этом номере.

блокировки экрана на телефоне нет — показ с предупреждением, что телефон не защищён. «Проверить
запись» — общий экран проверки трёх слов; «Слова записаны» больше не отмечает копию сделанной.

**«Данные не открываются»** (есть: `RecoveryScreen`) — в новом языке, тексты безличные
(«Данные откладываются, а не удаляются» вместо «Удалять её не будем, только отложим»).

## Контакты и группы (2026-11-01)

Макеты — артефакт «Контакты и группы Peerage» (`mockups/redesign/people/`). Владелец: новая
группа — **Б** (сначала участники, потом название; А — как сейчас, сначала название — отвергнут);
админ — **один, с передачей прав**; приветствие в запросе — **до беты** (шаг 7i). Сверено с
кодом 2026-11-01: «есть» — реализовано, остальное — новое.

**Добавить контакт.** Экран сразу открывает камеру (разрешение — в момент открытия); ниже
«Вставить код» и «Показать свой код». Код обмена — ключ, адрес и имя (есть: `ключ:адрес#имя`).

- Код распознан → кто это (имя из кода, начало ключа) и **«Приветствие»** — поле, текст которого
  и есть запрос в контакты (новое, шаг беты 7i; сейчас запросом становится первое сообщение
  чата). Подпись: уйдёт вместе с именем профиля, фото — после принятия. «Как подписать у себя» —
  необязательно (есть: локальное имя перекрывает присланное). Кнопка — «Отправить запрос».
- После отправки — чат в состоянии «запрос отправлен»: плашка «Сообщения ниже Алиса получит,
  когда примет его», приветствие и всё написанное дальше — с часами «ждёт принятия».
- Ошибки кода — разными словами (новое): «Это не код Peerage» · «Это код этого телефона» ·
  «Борис уже в контактах» + «Открыть чат».

**Мой код** — QR, имя, «Скопировать» · «Поделиться» · «Сканировать код». Адрес Yggdrasil уходит
в «Сеть»; знаки своего отпечатка убираются (сверка — одним набором на пару, раздел
«Безопасность»).

**Свой профиль** — фото и имя (есть); «Убрать фото» — новое. Пояснение: контакт может подписать
этот телефон у себя по-своему, и увидит своё имя вместо присланного (есть, `displayName`).

**Группы.** Админ один — создатель (есть: `admin_key`); только он удаляет участников (`remove_member`)
и закрепляет (`pin`); приглашать может любой участник (есть: `invite` без проверки на админа).

- **Новая группа — Б**: шаг 1 — выбор участников из контактов (поиск, выбранные чипами сверху),
  шаг 2 — название и фото группы, список «кто получит приглашение», строка «Создатель — админ:
  удаляет участников и закрепляет; приглашать может любой». Создание = `create` + `invite` каждому.
- **Пригласить**: несколько сразу; у контакта — «уже в группе» или «приглашён · ждёт ответа»
  (отправленные приглашения в базе есть — `sent_invites`; в UI не выведены — новое). Каждый
  получает карточку «Вступить / Отклонить» (есть).
- **Шторка участника** (админу): Написать · Профиль · **Передать права админа** (новое) ·
  красным «Удалить из группы» с пояснением, что группа сменит ключи (есть, ADR-004).
- **Выход админа** (новое): шторка «Этот телефон — админ группы» — без админа удалять участников и
  закреплять некому, а выход остальных становится только локальным (есть: `leave` шлёт запрос
  админу, `on_leave_request` отзывает); выбор преемника → «Передать … и выйти» / «Выйти без
  передачи». Решённое ранее «Сделать админом» в профиле группы заменяется передачей прав.
- **Правка группы** (админ): название и фото (новое; имя уже рассылается — `send_name`).

## Правила отделки (2026-11-01)

Прогон всех выбранных макетов по правилам отделки интерфейса; макеты поправлены под них.
При реализации — это требования к коду, не пожелания.

- **Радиусы — шкала 8 / 18 / 28, вложенные концентричны** (внешний = внутренний + отступ):
  панель 28 → группа 18 при отступе панели 10 → плитка/иконка в группе 8. Сейчас отступ панели
  был 16–18 и радиусы не сходились; цитата в пузыре — 10 (пузырь 18, отступ 8), миниатюра в
  группе медиа — 4.
- **Иконки — один набор, контур, толщина 1.5 при 20 dp** (под текст 400). Исключение — мелкие
  знаки ≤16 dp (галочки 1.8). Заливка — только активное состояние (выбранная вкладка, включённое
  «закреплено»). Состояния — `tint` одного вектора, не отдельные ресурсы. Глиф бренда
  (`ic_launcher_fg`) — свой, толщина 2, не трогать. Текстовые «+» и подобные — заменить векторами.
- **Обводка картинок** — 1 px белым 10 % поверх фото, видео, миниатюр и аватаров-картинок:
  `border(1.dp, Color.White.copy(alpha = 0.1f), shape)`. Не тонированный серый — он грязнит край.
- **Нажатие — масштаб 0.96** на кнопках, плитках, пилюлях действий. Не на строках списков
  (там — рипл/подсветка строки) и не на пузырях (там долгое нажатие = выделение ряда).
- **Смена иконки микрофон ↔ отправить** — перекрёстно: масштаб 0.25 → 1, прозрачность 0 → 1,
  размытие 4 → 0, пружина без отскока (`spring(dampingRatio = 1f)`). Так же — любая иконка,
  меняющая смысл на месте.
- **Уход полос-напоминаний** — затухание + сдвиг вверх на 8 dp через `animateItem`, не схлопывание
  на всю высоту. Появление при первом показе экрана — без анимации.
- **Частые события без анимации**: новые сообщения, счётчики, набор — мгновенно или ≤150 мс
  прозрачностью. Анимация никогда не единственный сигнал — у состояния есть и статичный признак
  (цвет, знак, подпись).
- **Заставка** — глиф центрировать оптически (у него тяжёлый низ слева), проверить на устройстве.

## Мелкие правки по ходу

- **Галочки доставки** — две, с частичным наложением (вторая заходит на первую), а не
  два отдельных знака «✓✓». Две = доставлено; «прочитано» — когда появятся отчёты о
  прочтении (по выбору, шаг 7c `docs/plans/beta.md`), отличается от «доставлено» заливкой/цветом.
- **Тексты категорий настроек** — под нейтральный тон: «Что мы не отправляем о вас» (Приватность)
  переписать без «мы/вы», при переносе категорий в «Профиль».
