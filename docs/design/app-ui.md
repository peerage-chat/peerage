# Дизайн приложения (Android) — живой спек

Источник истины по UI всего приложения (кроме экрана звонка — он в `call-ui.md`).
Заполняется по ходу дизайн-сессий (мокапы согласуются в чате, итог фиксируется тут).

**Как выглядит** — HTML-макеты в [`mockups/`](mockups/) (визуальный источник истины,
на токенах `Tokens.kt`); этот файл — *почему/поведение/навигация*. Реализация в
Compose — 1-в-1 по макету.

## Визуальный язык
- Тёмная база, акцент **Holo-голубой `#33B5E5`** (бренд). Приглушённый акцент пузыря
  `#245266`. Онлайн/verified — зелёные (`#8BC34A` / `#4CAF50`), ошибка `#E53935`.
- **Аватарки — КВАДРАТ со скруглением** (~радиус 14-15px на 48-50px), НЕ круг.
  Presence-точка — в **правом-нижнем** углу аватарки.
- Иконки — Tabler-стиль (не эмодзи). В одном баре все элементы **одной высоты**,
  по вертикали центрированы.
- Две насыщенности шрифта (400/500), sentence case, плотные ряды.

## Навигация (выбрано)
Эволюция варианта B (Telegram), НЕ нижняя панель — чтобы не было «бутерброда»:
- **Левое меню по свайпу/гамбургеру** (Telegram): шапка = профиль (аватар, «в сети ·
  N пиров», QR) + пункты **Контакты · Звонки · Сеть · Сохранённое · Настройки** +
  версия внизу. Ряды меню одной высоты, без инлайн-метрик.
- **Папки** — горизонтальный **рейл иконок** (Discord-стиль, вариант 3) на Главной;
  бейдж непрочитанного — мелкий, в **правом-нижнем** углу иконки; `+` создаёт папку.
- В шапке Главной — **крошечный индикатор пиров** (`⊹ 8`, тап → «Сеть»), статус меша
  виден даже без отдельной вкладки.
- Нижней панели НЕТ.

## Сквозные решения
- **Метаданные-индикаторы опциональны и ВЫКЛ по умолчанию**: read-receipts, «печатает»,
  last-seen (security-first, не светим метаданные). Галочки — только **доставка**
  (1 = отправлено, 2 = доставлено пиру), «прочитано» по умолчанию нет.
- **Папка = ФИЛЬТР/вид, а не контейнер**: чат может быть в нескольких папках сразу.
  Встроенные «умные» папки (Личные/Комнаты/Каналы/Боты) + кастомные в одном ряду.
- Адаптивность обязательна (планшет/ландшафт) — отдельный структурный проход
  (на планшете меню = постоянная панель слева, master-detail список+чат).
- **Fingerprint — СВОИ знаки, которые рисует приложение** (не эмодзи из шрифта).
  Сверка идёт глазами по двум экранам, а системные эмодзи рисует шрифт устройства:
  на разных вендорах один символ выглядит по-разному, и сверка ломается ровно там,
  где нужна. Знак = **форма (16) × цвет (16)** = 256 вариантов, то есть 8 бит; 12
  знаков сеткой 6×2 дают **96 бит** (у 8 слов BIP39 — 88). Форма первична (различима
  и без цвета), цвет вторичен. Рисуется на Canvas — байт-в-байт одинаково везде.
  Правило вывода живёт в ядре (`p2p_core::identity::visual_fingerprint`) и
  **версионировано** через домен-сепаратор: сменили набор — бампнули версию, старые
  сверки честно инвалидируются, а не расходятся молча.
  Слова BIP39 остаются рядом: их удобно диктовать голосом и они же — a11y-фолбэк
  (при дальтонизме цвет теряется, и на знаках остаётся 4 бита формы вместо 8).

## Экраны (согласовано)

### Главная (Чаты)
Топ-бар (гамбургер · «Чаты»/имя активной папки · индикатор пиров · поиск) → рейл
папок-иконок (активная подсвечена, бейдж в правом-нижнем углу, `+`) → список чатов
(квадр. аватар+presence, имя+verified, превью, время, непрочитанное/без звука) →
FAB «новый чат». Заголовок шапки = имя активной папки (различает иконки-папки).

### Папки
Telegram-модель. Редактор папки: имя, иконка, «Включить» (типы: Личные/Группы/
Комнаты + выбрать конкретные чаты), «Исключить» (без звука/прочитанные), живой счётчик.

### Личный чат (DM)
Шапка (назад · аватар+presence · имя+verified · статус · **звонок** (ТОЛЬКО аудио —
кнопки видеозвонка нет; камеру включают уже внутри звонка) · меню, иконки разнесены,
тап по шапке → профиль) → строка E2E («защищены сквозным
шифрованием») → чип даты → пузыри: входящие нейтральные `#24292F`, исходящие
приглушённый акцент `#245266`, **время в правом-нижнем углу ПОСЛЕДНЕЙ строки**
(absolute + спейсер), галочки доставки → голосовые/вложения → ввод: скрепка и
эмодзи **внутри поля-пилюли**, микрофон/отправка — отдельной кнопкой, всё 44px по центру.

### Сеть (mesh) — наш уникальный
Статус («Подключено к mesh») → метрики (Пиры/Пинг/Трафик ↓↑) → **Мой узел**
(Yggdrasil-адрес моно + копировать + Мой QR + Поделиться) → **Режим участия**
(тумблер «Узел сети» = ретрансляция; показываем ВЫГОДЫ — приоритет доставки, дольше
офлайн-TTL — и ЦЕНУ — батарея/трафик) → **Пиры** (направление вход/исход, адрес,
пинг с цветом: зелёный/янтарь/красный) → **Офлайн-очередь** («доставится, когда
получатель появится»).

### Профиль контакта
Шапка (назад · меню) → большая квадратная аватарка + имя + verified + статус →
действия (Сообщение / Звонок / Видео) → **карточка верификации**: статус
(зелёное «Проверен» / янтарное «Не проверен» + «Сканировать QR») и **эмодзи-
fingerprint сеткой 6×2** + пояснение «совпадает с её экраном → связь без посредника»
→ общие группы · уведомления · заблокировать.

### Настройки
Профиль-шапка (квадр. аватар, имя, короткий адрес, QR → редактировать) → группы:
**Конфиденциальность** («был(а) в сети» / «Отчёты о прочтении» / «Индикатор набора» —
тумблеры ВЫКЛ по умолчанию + подпись «не раскрываем метаданные»); **Безопасность**
(«Блокировка приложения», «Шифрование данных» → выбор уровня at-rest Keystore/пароль/
оба, «Резервная копия ключа» — янтарём «Не сделан», «Проверенные контакты»); **Медиа
и сеть** («Качество видео», «Сеть и батарея», «Хранилище»); футер версия + GPL.
Термины: «Сеть и батарея», «Хранилище», «Резервная копия ключа» (не «бэкап/энергия/кэш»).
**Хранилище** содержит и **резервную копию ДАННЫХ** (история/контакты) — отдельно от
резервной копии КЛЮЧА (идентичность): ключ восстанавливает личность, данные — переписку.

**Копия данных** (макет `mockups/data-backup.html`) — 5 шагов: состав → пароль →
процесс → (восстановление) → итог. Состав ВЫБИРАЕТ пользователь, и каждая часть
подписана цифрой (контакты, сообщения, заметки, звонки, вложения с размером): решение
«класть ли вложения» принимается по объёму, а не вслепую. Звонки выключены по умолчанию
— журнал локальный, вынос его наружу должен быть осознанным. Экран обязан говорить, чего
в копии НЕТ: ключа личности (он в копии КЛЮЧА) и групп (восстановленное MLS-состояние
устарело бы и сломало группу — приглашают заново). Пароль у копии свой, не ключ
устройства: файл открывается на ДРУГОМ устройстве, где ключа этого нет. Восстановление
— слияние: об этом сказано до нажатия, иначе человек боится потерять новое.

**Действия с сообщением (DM).** Долгий тап входит в режим выделения: верхняя панель
целиком заменяется на «N выбрано» + действия, короткий тап в этом режиме переключает
выбор (а не открывает вложение — иначе выбор был бы ловушкой). Ответ доступен только
при ОДНОМ выбранном: ответ на пять сообщений — не действие, а вопрос «на какое».
Удаление спрашивает: «у себя» всегда, «у всех» — только когда все выбранные наши, и
рядом сказано прямо, что отзыв это **просьба, а не гарантия** (собеседник мог
прочитать или сохранить раньше). Цитата ответа рисуется ССЫЛКОЙ в локальную историю
(ADR-006), поэтому удалённый оригинал показывается как «сообщение удалено», а не
расходящейся копией текста. В группах пока доступен только просмотр: групповые
сообщения не имеют идентификатора, и ответ/отзыв там — отдельная работа.

### Онбординг
Поток: 1) Приветствие — обещание приватности буллетами («без номера телефона / не читаем
контакты / не знаем, где вы») + Начать / Импортировать ключ. 2) Профиль (имя + аватар,
опционально). 3) **Резервная копия ключа** — янтарём «восстановить можно только этим
ключом»; сохранить в файл / показать фразу; **пропуск РАЗРЕШ�ёН** (с предупреждением +
плашка-напоминание в приложении). 4) Прайминг разрешений — экраном «зачем + Разрешить/
Позже», только уведомления + фон/батарея; камеру/микрофон/фото просим ПО ХОДУ (contextual),
контакты/гео/телефон не просим вообще.

КРИПТО-факт (для экранов ключа): сид-фраза = ПОЛНЫЙ ключ — кодирует 32-байтный ed25519-сид
(256 бит ≈ 24 слова BIP39), регенерирует всю личность. СЕКРЕТ. Не путать с verification-
fingerprint (8 слов/эмодзи) — тот из ПУБЛИЧНОГО ключа, не секрет. Сид восстанавливает
ЛИЧНОСТЬ, не историю (серверов нет). Экран фразы — `FLAG_SECURE` + «не фотографируйте».

### Контакты
Шапка (назад · поиск) → тайлы «Сканировать QR» / «Мой QR-код» (добавление ТОЛЬКО по
QR/ключу — синка телефонной книги нет, приватность) → группы «В сети» / «Все контакты»:
квадр. аватар + presence + имя + verified + статус. Контакт без имени — просто hex-адрес
(без подписи «имя не задано»). FAB нет — добавление через тайлы сверху. Тап → профиль.

### Групповой чат
Отличия от DM: шапка (аватар группы · имя · «N участников · M в сети» · звонок · меню,
тап → инфо группы). Под шапкой — **баннер активной комнаты** (зелёный): «N в звонке ·
имена» + кнопка **Войти** (центрирована, зелёная — комнаты = постоянные звонки). В
сообщениях — **имена отправителей цветом** (свой цвет на участника) + мелкие квадр.
аватарки (~36px, пропорционально пузырю) на входящих; свои — без имени. Системные строки
(«создала комнату»). Ввод как в DM.

### История звонков
Шапка (назад · «Звонки» · новый звонок) → фильтр Все/Пропущенные → строки: квадр.
аватар, имя+verified, **направление** (↗ исходящий / ↙ входящий зелёным, ↙ пропущенный —
красным), длительность, время, иконка перезвона (accent) справа. Звонки в комнатах —
аватар группы + «Звонок в комнате · длит.» + иконка → Войти.

### Глобальный поиск
Активное поле (назад · поиск · очистить) → результаты ГРУППАМИ: **Контакты / Чаты /
Сообщения**, с ПОДСВЕТКОЙ совпадения акцентом. Сообщения: аватар чата + имя + время +
сниппет с префиксом отправителя. Пустой запрос → «Недавнее» (история поисков).

### Мини-окно звонка (overlay, H4)
Свёрнутый активный звонок — плавающая ПЕРЕТАСКИВАЕМАЯ плашка поверх любого экрана.
Видео: мини-картинка (активный говорящий) + таймер + «развернуть»; низ — имя звонка +
микрофон + выход (красный). Аудио-звонок — то же, но аватар вместо видео. Тап →
разворот в полный экран звонка.

### Адаптив (планшет / ландшафт)
Через Compose `WindowSizeClass` — раскладки по брейкпоинтам ширины, НЕ по устройствам
(решение и приоритет платформ — [ADR-005](../adr/ADR-005-ui-adaptivity-platforms.md)).
Один набор size-agnostic контент-композаблов + оболочки, читающие size class.
**Compact** (<600dp, телефон-портрет): одна колонка, меню-
свайп, рейл папок сверху — как описано выше. **Medium** (600–840dp, планшет-портрет /
фолд / телефон-ландшафт): постоянный **nav-rail** слева + одна панель контента (меню-
свайп → rail, но ещё БЕЗ мастер-детали — дешёвая середина, чтобы не было скачка
Compact→Expanded). **Expanded** (>840dp, планшет / широкий ландшафт):
3 колонки — **nav-rail** (бывшее меню-свайп, теперь ПОСТОЯННОЕ: app-mark · Чаты/
Контакты/Звонки/Сеть · настройки + аватар профиля снизу) → **список** (рейл папок +
чаты, выбранный подсвечен левой акцентной полосой) → **детали** (открытый чат; пусто →
«Выберите чат»). Те же компоненты, переразложены: меню→rail, одна панель→две. Сетка
звонка сама добавляет колонки в ландшафте.
