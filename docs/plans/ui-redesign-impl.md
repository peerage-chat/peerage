# План реализации перепроектированного UI (2026-11-01)

Как довести Compose до [app-ui.md](../design/app-ui.md): порядок, объём, что уже есть в коде и
что нужно от движка. Вид — только по холстам [mockups/redesign/](../design/mockups/redesign/README.md),
1-в-1. Заменяет [ui-completion-plan.md](../design/ui-completion-plan.md) (тот — про язык июня 2026).

## Как идём

- **Основа первой.** Токены и общие компоненты — до экранов: каждый экран потом собирается из
  готового, и язык не расходится между экранами. Экран, переведённый раньше основы, пришлось бы
  переделывать второй раз.
- **Экран за экраном, целиком.** Экран переводится на новый язык за один заход вместе со своими
  новыми кусками («новое» в `app-ui.md`), без промежуточных заплаток.
- **Шаги беты, которые рисуют экран** (7c–7k), делаются сразу в новом языке — в той фазе, где их
  экран. Движковая часть шага может идти раньше, отдельным коммитом.
- **Приёмка экрана**: скриншот эмулятора на шрифте 1.0, 1.3 и 2.0 (однодевайсное — проверяю сам);
  сетевое и двухдевайсное — юзер на телефоне. `ktlintFormat`, `graphify update .`, коммит.
- **Новое в коде — на `Tokens.*`**, без инлайн-цветов и магических dp (инвариант 5).

## Место в плане беты

Решение владельца 2026-11-01: весь план (фазы 0–6) — шаг беты **7l**; мягкая заморозка формата
и раздача (шаг 8) — в самом конце, после всего остального.
