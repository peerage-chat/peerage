# Выкладка в Google Play

**Статус: отложено** (записано 2026-11-25). Сейчас раздача — GitHub (pre-release) с
автообновлением. Сроки правил Play — по состоянию на середину 2026 года; перед стартом сверить
с текущими требованиями Play Console.

## Цель

Peerage в Play — вторым каналом рядом с GitHub, без отказа от принципов: нет серверов, нет
сбора данных, исходники и сборка проверяемы.

## Шаги

### P0. Технические блокеры (в коде)

1. **`targetSdk` → требуемый Play** (на конец 2026 — 35, вероятно уже 36; сейчас 34).
   С 35 edge-to-edge принудительный: весь UI на инсеты (сейчас adjustResize без edge-to-edge,
   `rememberImeVisible()` в Components.kt держится на этом). Самый крупный шаг.
2. **Сборка-вариант `play`** (product flavor): без апдейтера (`Updater`, полоса обновления,
   строка в настройках) и без `REQUEST_INSTALL_PACKAGES` — Play запрещает обновляться в обход
   Play. Вариант `github` остаётся как есть.
3. **Фоновая служба.** `dataSync` при targetSdk 35+ ограничен ~6 ч в сутки — постоянный узел
   меша (режим A, память `project_power_model`) переводить на `specialUse` с подтипом и
   обоснованием. Проверить, что звонковая служба (`microphone|dataSync`) не упирается в лимит.
4. **AAB** вместо APK для варианта `play`; `release.sh` — вторая цель сборки. Воспроизводимость
   (`repro-build.sh --check`) — только при D1 = (б).

### P1. Аккаунт и закрытый тест

- Аккаунт разработчика: разовый взнос, проверка личности.
- Личный аккаунт: закрытый тест — не меньше 12 тестеров, 14 дней подряд с установленным
  приложением, только потом доступ к открытой выкладке. Тестеры беты подходят, нужны их
  Google-аккаунты.

### P2. Декларации в Play Console

| Что | Ответ для Peerage |
|---|---|
| Политика конфиденциальности | публичная ссылка (текст — отдельная задача) |
| Data safety | разработчик ничего не собирает; передача между пользователями — E2E, по действию пользователя |
| Службы переднего плана | `specialUse` (узел меша) и `microphone` (звонок) — описание + короткое видео |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | мессенджер без FCM, доставка требует постоянного соединения |
| `USE_FULL_SCREEN_INTENT` | входящий звонок |
| Удаление аккаунта | серверных аккаунтов нет; личность и данные — на устройстве, удаляются с ним |
| Возрастной рейтинг (IARC), аудитория | анкета; аудитория — не дети |
| Шифрование / экспорт | открытый код с публичной криптографией — исключение EAR, отдельных бумаг нет |
| Пользовательский контент | личные чаты и группы — блокировка есть; **публичные каналы** потребуют жалоб и модерации — решить до их выпуска в Play |

### P3. Карточка магазина

Иконка 512×512, баннер 1024×500, 2+ скриншота телефона (ru/en), краткое (до 80 знаков) и
полное описание. Имя «Peerage» — проверить на товарные знаки в классе ПО (BRAND.md).

## Риски

- **Проверка разработчиков вне Play.** Google с 2026 года поэтапно вводит обязательную
  регистрацию разработчика и для установки APK не из Play на сертифицированных устройствах.
  Может затронуть раздачу с GitHub независимо от этого плана — следить отдельно.
- Ревьюер может не принять обоснование `specialUse` или исключения из оптимизации батареи —
  тогда фоновая доставка в варианте `play` хуже, чем в `github`.
