# Scope v1.0 (Android-only) + заявка NLnet

**Статус:** черновик к согласованию · **Дата:** 2026-06-27
Связано: [ROADMAP](ROADMAP.md), [SUBSYSTEMS](SUBSYSTEMS.md), [ADR-003 API движка](adr/ADR-003-engine-api.md).

## Цель 1.0 (одним абзацем)
Серверлесс E2E-мессенджер на Yggdrasil-mesh, которым приватный пользователь может
**пользоваться ежедневно на Android**: чат 1:1 и группы, звонки/комнаты, медиа в
чате (аватарки/картинки/файлы), офлайн-доставка, понятный онбординг с резервной
копией ключа. Без своего сервера для данных (единственное внешнее — опц.
push-пробуждение). Открытый протокол, воспроизводимая сборка, security-review.

**Платформа 1.0:** Android. Десктоп (Slint) — эталон/dev-инструмент, под релиз не
шлифуется (решение 2026-06-27).

## Почему NLnet (NGI Zero Core)
Мэтч близкий к идеальному: free software (GPL-3.0 ✓), децентрализация без серверов,
приватность/анти-метаданные, открытый протокол, воспроизводимость, готовность к
независимому аудиту. NGI Zero финансирует **конкретные deliverables с вехами**
(типично разбивка на 5–10 задач). Сильные стороны заявки именно для них:
- **Serverless-архитектура** (нет central point — ни данных, ни метаданных).
- **Security-first**: E2E (NaCl + MLS), at-rest vault, anti-replay, план верификации
  лестницей (фаззинг/Kani → TLA+/Tamarin).
- **Спека протокола + threat model** как артефакты (не только код).

## Отложить за 1.0 (явно вне скоупа)
- Торрент-стриминг / совместный просмотр (Фаза F).
- **Multi-device** (P8 — крупно, нужна модель устройств).
- Android screen-share (MediaProjection).
- Большие звонки: SFU/simulcast вместо full-mesh (P9).
- Десктоп-паритет под релиз.
- TLA+ протокола / Tamarin крипто-обвязки (post-1.0, на стабильных контрактах).

## Вехи под заявку (черновик deliverables)
Разбивка под формат NGI Zero (каждая = осязаемый результат с DoD). Бюджет/недели —
ориентир, уточнить.

- **M1 — Контракт движка + спека.** ADR-003 в код: `engine`-крейт, Command/Event,
  JNI-кодек, репатриация стата Сети + офлайн-TTL + презенс. Спека протокола.
  *DoD:* клиент не считает домейн-логику; движок юнит-тестируется без устройства.
- **M2 — Блобы + медиа в чате.** Крейт `blob` (BLAKE3, чанки, pull, лимиты/анти-DoS);
  потребители — аватарки, картинки, файлы. *DoD:* отправка/приём картинки и файла,
  аватарки сверяются по хэшу.
- **M3 — Офлайн/презенс хардненинг.** Усиление S6 поверх foreground-сервиса.
  *DoD:* сообщение доходит после возврата получателя в сеть; без потерь/дублей.
- **M4 — Онбординг, ключ, настройки.** Первый запуск, резервная копия ключа
  (сид-фраза/файл, FLAG_SECURE), экраны настроек (энергия/медиа/хранилище).
  *DoD:* новый пользователь регистрируется и делает бэкап ключа; настройки не
  захардкожены.
- **M5 — Security-review.** Фаззинг (`cargo-fuzz`) + `proptest` на парсеры
  недоверенных байт; Kani-харнессы на 2–3 парсера; аудит блоб-поверхности.
  *DoD:* парсеры не паникуют ни на каком входе (CI-фаззинг); отчёт аудита.
- **M6 — Релиз-инженерия.** Воспроизводимая сборка, F-Droid-метаданные, доки
  (спека протокола, threat model, build/run). *DoD:* воспроизводимый APK; страница
  F-Droid; пользователь собирает из исходников по доке.
